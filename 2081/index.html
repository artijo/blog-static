ไอ้อาร์ตกลับมาแล้วว่ะ (อัปเดตเว็บใหม่)

19 มิถุนายน, 202314 กรกฎาคม, 2023

สวัสดีคร้าบบบบบบบบบ… หายไปนานกับการเขียนบล็อกที่ไร้สาระภาษาเพี้ยนและหยาบคายในบางครั้งของไอ้อาร์ต สาเหตุที่หายไปน่ะหรอ เพราะขี้เกียจ!!!.. อะล้อเล่น เพราะเพิ่งว่างไงล่ะ อันที่จริงก็ไม่ได้ว่างหรอกแต่คิดว่าทำตัวให้ว่างก็น่าจะว่างแหละ งงไหม?

ยังไงหายไปนานล่ะขออัปเดตความเปลี่ยนแปลงบล็อกแห่งนี้นิดนึงมีอะไรหลายๆอย่าง ที่อาจจะเปลี่ยนไป หรือบางคนที่เข้ามาบล็อกบ่อยๆก็อาจจะเห็นแล้วบ้าง

อัปเดตความเปลี่ยนแปลงของเว็บบล็อก

ธีม จากที่เมื่อก่อนได้ใช้ธีมแนว Full Site Editing ใช้ไปได้สักพักรู้สึกมีอะไรหลายๆอย่างยังขัดใจอยู่ อย่างการเพิ่มฟอนต์ในตัวธีมเลย ต้องทำไงวะพอไปแก้ที่โค้ดธีม ธีมส่งอัปเดตออกมา ไอ้ชิบหายที่แก้โค้ดไว้ก็หายหมด อาจจะพอมีทางแก้บ้างอย่างใช้ปลั๊กอินช่วย แต่ไอ้อาร์ตเป็นโรคจิตอย่างนึงที่ในเมื่อตัวธีมมันสามารถทำได้เลยไม่อยากใช้ปลั๊กอินให้มันรก (ถึงแม้จะไม่ขนาดนั้นก็เถอะ) เลยได้กลับมาใช้ธีมแบบ Classic เหมือนเดิม เปลี่ยนไปเปลี่ยนมาอยู่สองธีม ใครที่เข้าดูบ่อยๆอาจจะรู้ แต่คิดว่าธีมนี้ลงตัวที่สุดล่ะ

และได้เปลี่ยนฟอนต์หัวใหม่นิดหน่อย หามาหลายๆ ตัวอย่าง LineSeed, Anuphan, Anakotmai ส่วนตัวชอบ LineSeed ที่สุด แต่ไอ้อาร์ตได้นำฟอนต์นี้ไปใส่ในโปรเจครายวิชานึงและโดน Feedback ว่า “ฟอนต์ไม่สวยเลย” ไอ้อาร์ตเสียใจมากเพราะนำฟอนต์นี้ไปใช้หลายงานทั้งของตัวเองและลูกค้า ไอ้อาร์ตเลยไม่ใช้ฟอนต์นี้ในบล็อกตัวเอง เลยใช้ฟอนต์ Anakotmai แทน

ส่วนการ Cache ใช้ Object ของ Redis แคช Database ใช้ instantpage ที่ช่วยโหลดก่อน เวลาเอาเมาส์ไป Hover (ใครที่ลองจิ้มเล่นในคอมจะรู้ว่า มันเร็วมากกกกกกกกกกกกกก) บีบ JS, CSS, HTML และวิ่งผ่าน Cloudflare (ทุกอย่างจบที่ LiteSpeed Cache)

ในส่วนของ Media ในเว็บได้ใช้วิธี Offload ไปยัง Cloudflare R2 แทนการอัปโหลดขึ้นไป Server Host โดยตรง

ในส่วนระบบคอมเมนต์ตอนนี้ยังปิดไว้อยู่ ไว้ทำ Privacy-Policy ก่อนเดี๋ยวมาเปิดให้นะ

และระบบเก็บสถิติการเข้าใช้งานเว็บไซต์ ยังใช้ Cloudflare Web Analytics ที่ไม่มีการระบุตัวตนเหมือนเดิม เลยไม่มีคำเตือนขอคุกกี้เพื่อเข้าถึงเว็บครับ
