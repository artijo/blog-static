ติดตั้ง ghost บน aws lightsail

9 ตุลาคม, 202128 มิถุนายน, 2023

Ghost เป็น blogging platform ที่มีขนาดเล็กทำงานได้รวดเร็ว คุณสามารถใช้ Ghost เพื่อเขียนหรืออ่าน Blog ได้ในทุกๆ อุปกรณ์ และสามารถปรับแต่งได้ง่ายเนื่องจากโครงสร้างเป็น JavaScript และยังดีต่อ SEO โดยไม่ต้องปรับแต่งอะไรเพิ่มเติมเลย

วิธีนี้สามารถติดตั้งที่ Cloud VPS เจ้าอื่นก็ได้ แต่วันนี้จะมาสาธิตที่ aws lightsail ครับ

สร้าง Instance lightsail

ขั้นตอนแรกไปที่ https://lightsail.aws.amazon.com ทำการสมัครให้เรียบร้อย คิดว่าทุกคนทำเป็นอยู่แล้ว เมื่อสมัครเรียบร้อยหมดแล้วจะเป็นหน้าตาแบบนี้

จากนั้นทำการสร้าง Instance โดยเลือกที่ Create instance

ในส่วน Instance Location แนะนำให้เลือก Singapore (เพราะใกล้ประเทศไทยที่สุด เวลาเรียกใช้จะได้ไม่โหลดนาน) จะเลือก Zone ไหนก็ได้

Instance image เลือก Linux/Unix –> OS Only –> ให้เลือก Ubuntu จะให้ V.ไหนก็ได้ (lightsail มี ghost app ให้เลือกให้เลือกติดตั้งแบบ 1-click-install ได้แต่ผมไม่ค่อยแนะนำ เพราะมันไม่ใช่เวอร์ชันล่าสุด เดี๋ยวมางมอัปเดทอีก)

Instance plan ให้เลือกอย่างต่ำคือตัว 5$ เพราะตัวที่ต่ำกว่านี้จะไม่สามารถติดตั้ง ghost ได้ เพราะ swap ram ไม่พอ

Identify instance ตั้งชื่อ Instance อะไรก็ได้

จากนั้นกด Create Instance ได้เลยและรอสักพัก

Config Firewall

จากนั้นทำการ Config Firewall เปิดพอร์ต 443 เพราะให้สามารถใช้ HTTPS ได้ โดยจิ้มที่สามจุด–>Mange

เลือกเมนู Networking จิ้มที่ Add rule แล้วเลือก HTTPS แล้ว Create ได้เลย

สร้าง Static IP

เนื่องจากตอนนี้ Public IP Instance ของเรายังเป็น Dynamic IP อยู่(ไอพีเปลี่ยนไปเรื่อยๆเมื่อ Instance ถูก Reboot) เราต้องไป Static IP ให้ Instance ของเราเพื่อจะให้ IP ไม่เปลี่ยนไปเรื่อยๆ

ไปที่ Networking แล้ว Create static IP

Attach to an instance ให้เลือก instance ของเรา

Identify static IP ตั้งชื่อ Static IP อะไรก็ได้

จากนั้นกด Create ได้เลย

แล้วเราก็จะได้ IP Static มาซึ่งเราจะใช้ IP นี้ในก็ชี้ Domain Name มาที่ ghost ของเรา

เตรียมการติดตั้ง ghost

เปิด Terminal ของ Instance โดยจิ้มที่ไอคอน Terminal ข้างๆสามจุด จากนั้นก็พิมพ์คำสั่งตามข้างล่างนี้เลย

สร้าง User ใหม่

# สร้าง User ใหม่

adduser <user>

Note: <user> ใช้ user ชื่ออะไรก็ได้ เช่น ghost
# เพิ่ม user ที่สร้างใหม่ไปที่ administrator Group

usermod -aG sudo <user>

# Login ไปที่ User ใหม่

su - <user>

Update packages

sudo apt-get update

sudo apt-get upgrade

ติดตั้ง NGINX

sudo apt-get install nginx

# เปิด firewall เพื่อนให้ nginx เข้าถึง https ได้

sudo ufw allow 'Nginx Full'

ติดตั้ง MySQL

sudo apt-get install mysql-server

หากใช้ Ubuntu 18.04 หรือ 20.04 ต้องใช้รหัสผ่านเพื่อให้เข้ากันได้กับ Ghost-CLI ทำตามขั้นตอนต่อไปนี้

sudo mysql

# อัปเดทชื่อผู้ใช้
# แทนที่ 'password' ด้วยรหัสผ่านที่ต้องการ แต่เก็บเครื่องหมาย'คำพูด'ไว้

ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'password';

quit

ติดตั้ง Node.js

# เพิ่มที่เก็บ NodeSource APT สำหรับ Node 14

curl -sL https://deb.nodesource.com/setup_14.x | sudo -E bash

# ติดตั้ง Node.js

sudo apt-get install -y nodejs

ติดตั้ง Ghost-CLI

sudo npm install ghost-cli@latest -g

Create a directory

# สร้างไดเร็กทอรี: เปลี่ยน `sitename' ตามต้องการ

sudo mkdir -p /var/www/sitename

# ตั้งค่าเจ้าของไดเรกทอรี: แทนที่ <user> ด้วยชื่อผู้ใช้ที่ตั้งไว้ตั้งแต่ตอนแรก

sudo chown <user>:<user> /var/www/sitename

# ตั้งค่าการอนุญาตที่ถูกต้อง

sudo chmod 775 /var/www/sitename

# ไปที่โฟลเดอร์

cd /var/www/sitename

ติดตั้ง ghost

ghost install

ในระหว่างการติดตั้ง ระบบจะถามดังนี้

Blog URL ใส่ที่อยู่ของเว็บไซต์ เช่น https://example.com แล้วอย่าลืมชี้โดเมนมาที่ IP ที่ได้ Static ไว้ด้วยสำหรับวิธีชี้โดเมนก็ลองหาในอาจารย์กรูก็ได้

MySQL hostname ระบบจะแสดงมาเป็น localhost ไม่ต้องเปลี่ยนอะไร กด Enter ไปได้เลย

MySQL username / password username จะเป็น root ส่วน password ก็ใส่ตามที่ได้ตั้งไว้ตอนติดตั้ง MySQL

Ghost database name อันนนี้ระบบจะใส่ให้อัตโนมัติ กด Enter ไปได้เลย

Set up a ghost MySQL user กด Enter ไปได้เลย

Set up NGINX กด Enter ไปได้เลย

Set up SSL ให้กด Enter เพื่อติดตั้ง SSL ด้วย แต่ถ้าระบบไม่ได้ถาม เมื่อติดตั้ง ghost เสร็จแล้วให้ใช้คำสั่ง ghost setup ssl ระบบจะถาม Email ก็ใส่ไป

จากนั้นเมื่อเสร็จแล้วไปที่ https://example.com/ghost เพื่อตั้งค่า บัญชี ghost เป็นอันเสร็จจ้า
