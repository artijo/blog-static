Twitter ลิมิตการโหลดอ่านทวีต? เพื่อ…

2 กรกฎาคม, 202314 กรกฎาคม, 2023

เมื่อเช้าตื่นขี้นมาไถวิตเตอร์ไปเรื่อย เจอเทรนด์อันดับ 1 #ทวิตล่ม ก็ไม่ได้ให้ความสนใจเท่าไหร่ จนไปเจอทวีต Elon บอกว่า

คุณตื่นจากภวังค์ลึก
ถอยห่างจากโทรศัพท์
เพื่อพบเจอเพื่อนๆและครอบครัวของคุณ

ไอ้เราก็งงว่ามีอะไรหว่าาาา หรืออีลอนพร่ามอะไรไปเรื่อยอีก สักพักเจอทวีต บอกว่าจะลิมิตการมองเห็นทวิต ด้วยบัญชีปกติที่ 600 ทวีตต่อวัน และบัญชีที่ Verified 6,000 ทวีตต่อวัน และบัญชีที่สมัครใหม่ไม่ Verified 300 ทวีตต่อวัน ไอ้นี่ก็งง แบบห้ะจริงดิเพื่ออะไร แต่แล้วด้วยแรงกดดันและแรงด่าชาวทวิตเตี้ยน ทำให้อีลอนปรับโควต้าใหม่ที่

  • บัญชีสมัครใหม่ไม่ Verified ที่ 500 ทวีตต่อวัน
  • บัญชีปกติที่ไม่ Verified 1,000 ทวีตต่อวัน
  • บัญชีที่ Verified 10,000 ทวีตต่อวัน

ซึ่งเอาจริงสำหรับผมที่หลังๆไม่ค่อยได้เล่นทวิตเท่าไหร่ก็ไม่ได้ซีเรียสอะไรกับตัวเลขนี้ คงใช้ไม่ถึงหรอกและจนตอนนี้ 20.30น ของวันที่ผมเล่นทวิตมารวมทั้งวันยังใช้ได้ปกติ ซึ่งนั่นคือยังไม่ถึง 1,000 ทวัต แต่ผมก็อดคิดไม่ได้ว่า

จะลิมิตไปทำไม?

ย้อนไปหลังจากที่อีลอน ซื้อ Twitter มาทำให้สถานะการณ์ภายในนั้นปั่นป่วนไปมากมายไม่ว่าจะปลดพนักงานออก 50% ด้วยอะไรหลายๆอย่างจนทำให้แบรนด์สินค้าต่างๆหยุดซื้อโฆษณาทำให้ Twitter รายได้ลดลงอย่างมาก ด้วยเหตุนี้จึทำให้อีลอนสั่งทีมวิศวกรลดค่าใช้จ่าย Infrastructure ให้ได้ 1 พันล้านดอลลาร์ต่อปี ทวิตเตอร์ต้องเปิดบริการ Twitter Blue เพื่อเป็นรายได้อีกทาง แต่นั่นก็ปลดเครื่องหมายติ๊กถูกสีฟ้าของอินฟูหรือคนดังรวมทั้งสำนักข่าวต่างๆออก เพื่อบีบให้ต้องมาสมัคร Twitter Blue ด้วยสถานะการณ์รายได้เช่นนี้ทวิตเตอร์ไม่ชำระค่าเช่าที่สำนักงานสหรัฐฯและทั่วโลกติดต่อกันหลายสัปดาห์ จนต้องปิดสำนักงานในเมืองซีแอทเทิล ต่อมาได้บล็อก 3rd Party Clients ทำให้มีไคลเอนต์อื่นๆเช่น Twitterific, Tweetbot ไม่สามารถใช้งานได้ ต่อมาก็ได้จำกัดการยืนยันตัวตน 2FA ผ่าน SMS เฉพาะสมาชิก Blue เท่านั้น จนมาถึงเรื่องของ Cloud Twitter ไม่ยอมจ่ายค่า Cloud ให้ AWS และ Google Cloud โดยภายหลังกลับไปจ่ายให้ Google Cloud แล้ว จนล่าสุดจำกัดการอ่านทวีตต่อวัน

จากข่าวต่างๆทั้งหมดนั้นปัญหาของทวิตเตอร์น่าจะอยู่ที่เรื่องรายได้เป็นหลักทวิตเตอร์จึงทำทุกทางที่ละลดค่าใช้จ่ายต่างๆให้ได้มากที่สุด ตั้งแต่ไล่พนักงานออกจนทำให้ระบบภายในเละ ลดค่าใช้จ่า Infastructure ซึ่งเป็นสิ่งที่สำคัญมาก เปิดบริการ Twitter Blue และทำทุกทางเพื่อให้ผู้ใช้หันมาสมัครใช้บริการ Twitter Blue ปิดให้บริการ 2FA ผ่าน SMS เพื่อลดค่าใช้จ่าย SMS ส่วนการจำกัดการอ่านทวีตต่อวันนั้นผมคิดว่าน่าจะมาจากความต้องการที่จะลดค่าใช้จ่าย Cloud เหมือนกัน

ล่ะต่อไปสายเผือกเรื่องชาวบ้านเยอะๆจะอยู่ยังไงกันนะ
