โดนแฮคบัญชี Steam!

7 พฤศจิกายน, 202128 มิถุนายน, 2023

เช้าวันที่ 7 พฤศจิกายน 2021 ผมตื่นขึ้นมาพร้อมกับเห็นแจ้งเตือนข้อความใน Discord ว่า

ข้อความนี้ไม่ได้ถูกส่งมาโดย Discord นะครับ แต่ถูกส่งมาโดยบอทตัวนึงผ่านห้องแชทเซิฟเวอร์โดยติด mention @everyone ด้วย โดยเมื่อคลิกเข้าไปก็ไปเจอหน้านี้ 3 months of Discord Nitro free from STEAM (discocrd-gift.com)

ซึ่งผมในตอนนั้นไม่ได้คิดอะไรมากเลยกดเข้าไปโดยเร็ว เพราะอยากจะได้ Discord Nitro เพราะโดยส่วนตัวก็ยังไม่เคยใช้เหมือนกัน

พอกดเข้าไปที่หน้าเว็บนั้นไม่เอะใจอะไรเลยเพราะหน้าตาของเว็บเอาจริงๆมันเหมือนกับ discord.com ที่คุ้นเคยมากจึงตกขบวนคิดว่าเว็บนี้เป็นเว็บปลอมไป พอกดรับก็มีหน้าต่าง Login ก็มีหน้าต่าง Steam Login ขึ้นมา ผมก็ไม่ได้เอะใจอีก เพราะตอนนั้นผมเข้าผ่านมือถือด้วย มันป็อบอัพขึ้นมาแล้วช่อง Url ไม่ขึ้น ซึ่งผมมาแงะบนคอมทีหลังแล้วพบว่าป็อบอัพที่เด้งขึ้นมานั้น ไม่มี Url แต่มัน iframe มาจาก discord-gift.com/login ซึ่งถ้าเขาไปดูจะพบว่า มันเป็นหน้า Login Steam หลอก!!!

หลังจากที่ผมใส่ User Pass เข้าไปแล้วแน่นอนว่ามันจะถามหา Key OTP อีกรอบเพราะผมเปิด 2FA ไว้และแน่นอนว่าไอ้เว็บหลอกอันนี้มันก็ทำช่องให้ใส่เหมือน Login เว็บจริงเป๊ะๆเลย แน่นอนว่าผมก็กรอกไป ซึ่งการที่เข้าจะได้ OTP แล้วล็อกอินเข้าได้เขาต้องล็อกอินบัญชีผมเดี๋ยวนั้นเลย ซึ่งแน่นอนว่าสุดท้ายผมได้รับอีเมลจาก Steam ว่าบัญชีผมมีการเปลี่ยนอีเมลเรียบร้อย

ซึ่งในตอนนั้นผมก็ไม่ได้คิดอะไรมากนึกว่า discord เขาแจก Discord Nitro 3 เดือนจาก สตรีม จริงๆ เพราะเมื่อเข้าไปที่หน้าเว็บเอาจริงๆถ้าคนทั่วไปไม่ได้คิดไรมากก็คิดว่าเป็นเว็บ Discord จริงๆ แต่ผมมาจับสังเกตได้ตอนที่โดนแฮคแล้วคือ เมื่อเข้าไปลิงก์ที่เจ้าบอทตัวนั้นสั่งมาจะไปที่ discocrd-gift.com/nitro เอาจริงๆโดเมนนี้ผมก็ไม่ได้เอะใจอะไรเพราะ Discord Official เองก็ไม่ได้มีแค่ discord.com แต่ยังมี discordstatus.com และอื่นๆอีก ผมจริงไม่ได้เอะใจกับโดเมนนี้สักเท่าไหร่ แต่พอลบ slug nitro ออกเป็น 404 not found เฉยเลย โบ๊ะ 1 กับอีก โบ๊ะ 2 คือหน้า download ก็เป็น 404 เหมือนกัน

หลังจากโดยแฮคแล้วทำไงต่อ?

ผมทำการติดต่อหา Support Steam ที่ help.steampowered.com/th/wizard/HelpWithLogin ซึ่งสามารถพิมพ์เป็นภาษาไทยไปได้เลยครับ เจ้าหน้าที่ก็เป็นคนไทยคุยภาษาไทย โดยผมแจ้งรายละเอีดไปทุกอย่างว่าทำไปทำอะไรแล้วเกิดอะไรขึ้นกับบัญชีของผม ไม่นานเจ้าหน้าที่ก็ตอบกลับมาบอกว่าเพื่อเป็นการยืนยันตัวตนให้ส่งหลักฐานการซื้อสินค้าในสตรีมไปให้

ซึ่งผมก็ได้ส่งเป็นสลีป truewallet ที่ผมซื้อเกมล่าสุดไป ไม่นานเจ้าหน้าที่ก็ตอบกลับมาบอกว่าได้กู้คืนทุกอย่างให้แล้ว และส่ง User กับ Password ใหม่มาที่อีเมล
